PDF 工作台 1.3
==============

本地桌面 PDF 小工具。左侧选择功能，右侧操作；菜单可滚动。
文件处理不上传网络，所有输出放入新的结果文件夹，不直接覆盖原件。
当前提供 14 个功能：分离、合并、调整顺序、删除页、旋转页、PDF 转 Word、
提取文字、PDF 转图片、图片转 PDF、设置密码、移除密码、流压缩、水印、页码。

一、运行与升级
1. Windows x64，需要 Python 3.10+，安装时保留 Tcl/Tk，勾选 PATH 或保留 Launcher。
   官方下载：https://www.python.org/downloads/windows/
2. 完整解压后双击 start.bat。首次创建本目录的 .venv，从 PyPI 安装依赖，需要联网。
   以后依赖齐全时直接启动，日常处理无需联网。
3. v1.3 增加了 Word/图像/水印转换依赖。升级时可把本版源码和脚本复制到旧目录，
   保留原 .venv；第一次升级启动会补装缺少的依赖，不必删除重装整个环境。
4. 不要在压缩包内运行，不要以管理员身份启动（可能阻止资源管理器拖放）。
5. start.bat 是日常入口；build_exe.bat 是重新打包程序，不应每次启动都运行。

本包是源码运行包，不含预制 Windows EXE。Windows 实机和 EXE 打包验证边界
见 TEST_REPORT.txt；Linux 测试不能替代 Windows 实机测试。

二、文档整理
PDF 分离：拖入一份 PDF，填份数后“均分生成”，再修改每份起止页。
每份包含起止页；可以增加/移除某一份，允许重叠或跳页。
PDF 合并：拖入多份 PDF，选中后上移/下移/移除，按列表从上到下合并。
重复路径会跳过；某文件无效或密码输入取消时，仅跳过它，务必检查最终列表。
删除页面：输入 1,3-5 这样的页码；不能删完全部页面。
旋转页面：选择页码与顺时针 90/180/270 度，在原旋转基础上增加。

调整顺序：
- m 到 n 是要移动的连续范围，包含两端；m=n 时移动单页。
- t 是当前载入 PDF 的原始物理页码，不是移除页面后重新编号的位置。
- 可选插到 t “之前”或“之后”，默认之前。t 不能处于 [m,n] 内。
- 移动块内部顺序及其他页面相对顺序保持不变。
- 原序列 1,2,3,4,5，m=2,n=3,t=5：之前得到 1,4,2,3,5；之后得到 1,4,5,2,3。
- t=1 且之前可移到最前，t=总页数且之后可移到最后。
- 实时显示压缩页序；导出前再次确认。无变化规则会提示，仍可导出副本。
- 每次使用当前载入文件快照。若要连续执行不同移动，请重新载入上次输出。

所有页码都从 1 开始，指 PDF 的物理页序，不一定等于页面印刷的页码。
多页选择支持 1,3-5 与中文逗号，排序并去重，不支持倒写范围。

三、格式转换
PDF 转 Word：
- 选择文字型 PDF，另存为 .docx。文字和识别到的规则表格可编辑；图片仍为图片。
- 本版是基础内容重建，不是版式完全还原。尽量保留字号/粗斜体、页面尺寸及内容顺序。
- 字符间距、段落间距可能变化，双栏可能逐行混排；公式、跨页/合并单元格、页眉页脚
  需要在 Word 中手工整理。Word 页数可能与源 PDF 不同。
- 无 OCR：整份没有可提取文字时会拒绝，不能声称得到可编辑扫描文字。
- 混合文档中没有文字的图像页会以图片保留，完成提示说明哪些内容不可编辑。
- 若检测到无法重建的矢量图或表格内图片，会在文末附该原页参考图并在完成提示中说明。
  参考图只为保留视觉内容，不是 OCR；含公式等复杂内容仍应对照原 PDF 检查。
- PDF 的字体依赖阅读器/Word 字体替换；中文默认使用宋体，不嵌入第三方字体。

提取文字：导出 UTF-8 TXT，带原始物理页标记；无 OCR，阅读顺序可能需整理。
PDF 转图片：选页码、PNG/JPEG 和 36–300 DPI，渲染成图片，不是提取原始嵌图。
图片转 PDF：添加 1–100 张 PNG/JPEG/BMP/WebP 单帧图片，可排序/移除。
应用 EXIF 方向，透明区域变白；每图一页，页面尺寸由像素和 DPI（36–600）决定。
图像可能重编码，不属于无损归档。总像素上限 1 亿，超大图片请先缩小或分批。

四、保护与修饰
设置密码：两次输入同一密码，使用 AES-256，另存加密文件。
建议使用至少 12 位强密码；不得含空字符，UTF-8 编码后最多 127 字节。
密码不写入配置或日志，忘记密码无法由本工具恢复。
移除密码：加载时提供已知密码，另存无密码 PDF；不是破解。
压缩 PDF：仅压缩内容流，不缩小图像分辨率，不保证变小，结果可能变大。
完成提示会显示源文件和结果大小，原文件不变。
添加水印：选页码和文字，半透明斜向水印。支持基本中英文字符；可被 PDF 编辑器移除。
添加页码：底部中央。编号按原物理页位置连续：起始值 1、只选第 3 页，会显示 3。
水印/页码可能遮住原内容。旋转页会规范方向以使叠加文字保持正向。

重要：删除页面、水印和覆盖文字都不是安全涂黑功能，不能保证隐去页面内的敏感数据。
除“设置密码”以外，输出 PDF/Word/图片/文本不保留源文件密码保护。
所有改写都会影响数字签名有效性，请保留签名原件。

五、性能与边界
- PDF 使用载入时的内存快照；外部修改原文件后需重新载入。图片在执行时读取。
- 转换在后台运行，同一时间只运行一个任务，PDFium 不并发调用。
- 大文件加载可能短暂等待，大量页/图片会占用内存和磁盘，不适合超大文档。
- 原 PDF 目录书签不保证保留；复杂脚本、XFA、附件、跨页链接、PDF/A 不作保证。
- 合并普通表单时字段加 file001_ 等前缀避免同名冲突，依赖旧字段名的脚本可能需修改。
- 普通失败会清理不完整输出；强制终止、断电可能留下不完整文件夹。
- 输出完成后请抽查重要文档，尤其复杂版式、加密、签名、表单和扫描混合文档。

六、构建 EXE 与许可证
Windows 安装 Python 后运行 build_exe.bat。
成功后运行 dist\PDFWorkspace\PDFWorkspace.exe，分发必须保留整个目录。
脚本会收集实际依赖许可证到 THIRD_PARTY_LICENSES，请勿删除。
未签名的自建程序可能提示未知发布者；不要关闭系统安全功能。
源码不捆绑第三方库。依赖说明见 THIRD_PARTY_NOTICES.txt。
PDF 转 Word 不使用 PyMuPDF/pdf2docx；PDFium 原生组件拥有额外许可证，不能一概标成 MIT。

七、开发与排错
安装依赖：python -m pip install -r requirements.txt
启动界面：python app.py
测试：python -m unittest discover -s tests -v

app.py            桌面界面与任务调度
core.py           分离/合并/页序核心
word_export.py    Word 基础内容重建
extra_core.py     删除/旋转/文字/密码/图片合成
pdf_more.py        页面渲染/流压缩/水印/页码
collect_licenses.py  构建时收集上游许可证

启动失败请保留完整报错；拖放无响应可先点击选择文件；输出权限错误请换到自己的文档目录。
