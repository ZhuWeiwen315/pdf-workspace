PDF 工作台 1.2
==============

左边选择工具，右边进行操作。本版有“PDF 分离”“PDF 合并”和“调整顺序”。
日常处理只在本机进行，不上传文件，也不会修改原文件。

一、启动
1. 需要 Windows x64 和 Python 3.10 或更新版本，安装时保留 Tcl/Tk。
   官方下载：https://www.python.org/downloads/windows/
   勾选 Add Python to PATH，或保留 Python Launcher。
2. 完整解压压缩包，不要直接在压缩包内运行。
3. 双击 start.bat。首次会在软件目录内创建 .venv，从 PyPI 安装依赖，
   因此第一次需要联网。后续依赖齐全时无需联网。
4. 请不要以管理员身份启动，否则 Windows 权限隔离可能阻止拖放。

升级说明：如果你已运行过 v1.1，可关闭程序后，把本版文件复制到原来的
软件目录并替换同名源码/脚本，保留原来的 .venv 文件夹。依赖没有变化，
这种方式一般不需再次安装；如果每个版本解压到新目录，会建立新的环境。
日常运行 start.bat，不要反复运行 build_exe.bat（它是重新打包用的）。

二、PDF 分离
1. 点击左侧“PDF 分离”。
2. 拖入一个 PDF，或者点击右侧文件区域选择文件。
3. 界面显示总页数。填写份数，点击“均分生成”。
4. 逐行修改每一份的起始页和结束页，也可以增加或移除某一份。
   例如 10 页 PDF：1–3、4–8、9–10，得到三份 PDF。
5. 选择输出位置，点击“开始分离”。

页码从 1 开始，包含起止页。指 PDF 物理页面顺序，不一定等于页面印刷页码。
允许范围重叠，也允许跳过某些页。每次导出会创建新的结果文件夹。
更换源文件和重新生成范围会先确认，避免直接丢掉手工填写的范围。

三、PDF 合并
1. 点击左侧“PDF 合并”。
2. 拖入多个 PDF，或点击“添加文件”选择多份；也可以分多次添加。
3. 列表显示文件顺序、文件名和页数。
4. 选中某个文件，点击“上移”或“下移”调整顺序。
   最终按列表从上到下合并，每个文件内部页序不变。
5. “移除”只移出列表，不删除原文件。“清空”会要求确认。
6. 填写输出文件名，选择输出位置，点击“开始合并”。
7. 结果保存在新建的 merged_随机后缀 文件夹中。

至少需要两个文件。相同路径重复添加会跳过，避免无意重复。
无效文件会提示错误；取消输入某份文件的密码时，只跳过该文件。
添加完成后请检查列表数量和顺序，确认所需文件均已加入。
输出名称不能包含路径符号、Windows 禁用字符或 CON 等保留名称。
未填写 .pdf 扩展名时会自动添加。

四、调整顺序
1. 点击左侧“调整顺序”，拖入或选择一个 PDF。
2. 输入 m、n：原始 PDF 中要移动的连续页面，包括两端。
   m = n 时，只移动一页。
3. 输入 t：原始 PDF 中作为参照的目标页。
4. 选择插到 t 页“之前”或“之后”，默认是“之前”。
5. 查看“调整后的原始页码顺序”，确认后点击“确认并导出”。
6. 弹窗再次显示规则及完整压缩页序，选择确认才会写出结果。

规则说明：
- m、n、t 都指当前载入 PDF 的原始物理页码，从 1 开始。
  t 不是移除 m–n 后重新编号的页码，也不是输出的新页码。
- 必须满足 1 ≤ m ≤ n ≤ 总页数，t 在 1 到总页数之间。
- t 不能处于 m 到 n 内（包含端点）；单页 PDF 无法进行这种移动。
- 被移动的页面内部顺序不变，其余页面的相对顺序也不变。
- 选 t=1 且“之前”可以移到最前；选 t=总页数且“之后”可移到最后。
- 如果规则恰好不改变顺序，预览及确认弹窗会提示，仍可选择导出副本。
- 原顺序 1,2,3,4,5，m=2,n=3,t=5：
  “之前”结果为 1,4,2,3,5；“之后”结果为 1,4,5,2,3。
- 预览将连续递增页面压缩成“2–3”等范围，避免长文档刷满界面。
- 每次导出都以当前载入文件为准，不会原地更新源文件。
  如需连续进行多次不同移动，请把上次的输出重新载入。
- 结果保存到新建的 reordered_随机后缀 文件夹中，不覆盖原件。

五、页面切换和安全说明
- 左侧三种工具可以来回切换，各自的文件和设置会保留到关闭程序。
- 导出时暂不允许切换页面、重复执行或正常关闭，避免误操作。
- 程序使用载入时的文件快照；源文件之后被其他程序修改时，
  本次导出仍使用原来载入的内容。要使用新内容，请重新添加文件。
- 加密 PDF 需要提供已知密码，不提供破解功能。
- 输出 PDF 不保留源文件的密码保护，数字签名也不会保持有效。
  请保留原件，重要签名文件或隐私文件导出后自行核查。
- 普通页面文字、图片、页面尺寸、旋转和裁剪框按页面复制。
- 原目录书签不复制。合并时普通表单字段名会增加 file001_ 等前缀，
  防止不同文件的同名字段互相覆盖。
- 复杂表单脚本、XFA、附件、跨页链接、数字签名、PDF/A 合规等不保证。
  表单脚本若依赖原字段名，可能需要另行调整。
- 源文件读取到内存，首次加载大文件可能稍等，不适合超大 PDF。
- 导出报错时会尝试清理不完整结果；强制关机或结束进程可能留下残片。

六、构建 Windows EXE（可选）
在 Windows 上安装好 Python 后，双击 build_exe.bat。
成功后运行 dist\PDFWorkspace\PDFWorkspace.exe。
分发必须保留整个 dist\PDFWorkspace 文件夹，不能只拷贝 EXE。
构建需要联网安装 PyInstaller。未签名的自建程序可能显示未知发布者提示，
不要为了运行本程序关闭系统安全功能。

七、文件与故障排查
app.py              界面、侧边栏、拖放、后台导出
core.py             PDF 读取、分离、合并、顺序调整与校验
start.bat           Windows 安装依赖并启动
build_exe.bat       Windows EXE 打包脚本
requirements.txt    运行依赖版本
tests/              自动化测试
TEST_REPORT.txt     已验证结果与未验证边界

启动失败请保留窗口里的完整报错；拖放不响应时可先点击选择文件。
没有写入权限时，请选择自己的桌面或文档目录。

这是源码运行包，不含已构建的 Windows EXE。Windows 实机启动、拖放和
EXE 打包尚未验证。测试情况见 TEST_REPORT.txt，不把 Linux 测试当成 Windows 测试。
