Third-party dependencies / 第三方依赖说明
=======================================
This source package does not vendor third-party libraries. Dependencies are
installed from PyPI by start.bat. Each upstream project retains its own license;
this notice does not relicense those projects or the application's own source.

Direct runtime dependencies:
- pypdf 6.10.0: BSD-3-Clause
  https://github.com/py-pdf/pypdf/blob/main/LICENSE
- tkinterdnd2 0.4.3: MIT
  https://github.com/Eliav2/tkinterdnd2/blob/master/LICENSE
  Its bundled TkDnD Tcl/native code also carries separate permissive notices.
- pdfplumber 0.11.9: MIT
  https://github.com/jsvine/pdfplumber/blob/stable/LICENSE.txt
- python-docx 1.2.0: MIT
  https://github.com/python-openxml/python-docx/blob/master/LICENSE
- pypdfium2 5.14.0: Apache-2.0 / BSD-3-Clause components, plus PDFium and native
  dependency licenses. See upstream LICENSES and build license files:
  https://github.com/pypdfium2-team/pypdfium2

- ReportLab 4.4.9: BSD license (watermarks/page numbers)
  https://docs.reportlab.com/developerfaqs/

Transitive packages include pdfminer.six, Pillow, lxml, cryptography and others.
Their exact versions vary with Python/platform unless separately locked.
PyMuPDF/pdf2docx are not used by this converter.

Binary distribution:
The Windows build script runs collect_licenses.py after PyInstaller. It copies
installed distribution license files (including PDFium native dependencies)
into dist/PDFWorkspace/THIRD_PARTY_LICENSES. Keep this directory with the entire
application bundle. Review the actual built artifact before public release;
a successful source test is not proof of binary license completeness.

PyInstaller's bundling exception permits applications to use their own license
subject to their dependencies. https://pyinstaller.org/en/stable/license.html
Do not describe all bundled code as MIT or strip upstream copyright notices.
