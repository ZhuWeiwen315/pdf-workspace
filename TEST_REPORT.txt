  pypdfium2 5.14.0，ReportLab 4.4.9。
- Windows x64 / CPython 3.10 的依赖 wheel 解析（dry-run）通过，
  仅说明可解析安装包，不是 Windows 启动或 EXE 验证。
- collect_licenses.py 在 Linux 冒烟测试成功，包含 PDFium 18 个许可文件；
  Windows 构建仍须检查真实打包产物与许可证完整性。

尚未验证或不保证：
- Windows 实机、Windows 拖放、高 DPI、EXE 构建和启动。
- 所有复杂 PDF 的版式、跨栏顺序、公式、表格脚本/XFA、附件、跨页链接、
  数字签名、PDF/A 合规或无损归档；输出请对照原件抽查。
- 超大文档的性能上限、故意构造的恶意 PDF 安全审计。
- “压缩”不承诺变小；水印/删页不是敏感文字安全涂黑。
